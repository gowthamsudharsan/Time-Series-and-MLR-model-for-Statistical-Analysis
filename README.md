# Time-Series-and-MLR-model-for-Statistical-Analysis
The prediction of future values in this project, using two methods with two different data sets, will be done. First will be the method of applying time series forecasting with the ARIMA model, which makes predictions by looking at past trends of the variable in question. The other method involves multiple linear regression-forecasting outcomes based on more than one variable. We further use MAE and RMSE to check model performance and assumptions such as error variance and normality. It would now help in comparing which methodology, whether the time series analysis or MLR-would give more accurate predictions and better insights from data. Both the models are interpreted and evaluated based on the datasets provided for predictions.
